# Week 06: Biomedical Imaging Acquisition

## Focus

CT projection/back-projection, MRI k-space filtering, multi-coil imaging, undersampling, and SENSE reconstruction.

## Public Contents

- `code/` contains MATLAB functions and demo scripts for projection, back-projection, k-space filtering, and SENSE reconstruction.
- `results/` contains selected MRI k-space and SENSE reconstruction figures.

## Excluded Contents

Course skeleton folders, large or support-only input files, submitted reports, and copied instruction materials are excluded.

## Reproducibility Note

Some demo scripts may refer to omitted local course `.mat` files. The retained code and figures document the workflow without publishing those support files.
