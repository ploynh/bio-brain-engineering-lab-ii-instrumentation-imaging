# Week 04: DAQ and LabVIEW Programming

## Focus

NI USB-6009 data acquisition, LabVIEW waveform measurement, RC transient analysis, and FIR filter design.

## Public Contents

- `code/` contains the MATLAB RC and FIR design script.
- `data/` contains small `.lvm` exports from LabVIEW/DAQ exercises.
- `results/` contains selected LabVIEW screenshots and MATLAB response figures.

## Excluded Contents

Submitted reports, course manuals, and duplicated raw working files are excluded.

## Reproducibility Note

The `.lvm` files are included as safe measurement examples. Hardware recreation would require the original DAQ setup.
