# Week 08: Gold Nanoparticle Characterization

## Focus

Gold nanosphere and nanorod characterization using absorbance, DLS, and photothermal-effect measurements.

## Public Contents

- `data/` contains small measurement spreadsheets and text files for absorbance, DLS, and photothermal analysis.

## Excluded Contents

Lecture videos, experiment videos, submitted reports, and course handouts are excluded.

## Reproducibility Note

This week is mostly experimental measurement analysis, so the public repository keeps safe measurement files rather than creating placeholder code or result folders.
