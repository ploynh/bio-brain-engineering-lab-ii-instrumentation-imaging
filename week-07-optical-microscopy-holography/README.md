# Week 07: Optical Microscopy and Holography

## Focus

Off-axis holography reconstruction and Fourier-domain microscopy analysis.

## Public Contents

- `code/` contains the MATLAB holography reconstruction script.
- `data/` contains a small sample hologram `.mat` file.
- `results/` contains selected raw, Fourier-space, cropped, intensity, and phase reconstruction figures.

## Excluded Contents

Large raw microscope image files, submitted reports, and copied course materials are excluded.

## Reproducibility Note

The included sample data and figures support public review of the reconstruction workflow without publishing the full raw image set.
