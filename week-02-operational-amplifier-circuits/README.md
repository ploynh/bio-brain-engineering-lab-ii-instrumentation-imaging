# Week 02: Operational Amplifier Circuits

## Focus

LM741 operational-amplifier experiments, including voltage detection, inverting and non-inverting amplification, adder/subtractor behavior, and instrumentation-amplifier measurements.

## Public Contents

- `data/` contains small oscilloscope measurement CSV files.
- `results/` contains a selected non-identifying voltage-detector result figure.

## Excluded Contents

Submitted reports, raw circuit-photo dumps, and course handouts are excluded.

## Reproducibility Note

This week is mostly measurement-oriented, so the public repository preserves safe measurement exports rather than adding artificial code files.
