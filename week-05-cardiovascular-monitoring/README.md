# Week 05: Cardiovascular Monitoring

## Focus

ECG/PPG monitoring concepts, digital FIR filter design, and LabVIEW-based PPG monitoring.

## Public Contents

- `code/` contains the MATLAB FIR filter design script and LabVIEW VI.
- `results/` contains selected filter-design response figures.

## Excluded Contents

Personal ECG/PPG waveform outputs, raw physiological recordings, circuit photos, and submitted reports are excluded.

## Reproducibility Note

The public files show the filter-design and VI structure. Personal physiological data from the lab session are not published.
