# Week 09: Fluorescence and Raman Sensing

## Focus

SERS and fluorescence analysis, including baseline correction, Raman peak comparison, fluorescence intensity comparison, and unknown-sample estimation.

## Public Contents

- `code/` contains MATLAB analysis scripts for Raman/fluorescence processing and unknown-sample analysis.
- `data/` contains Raman spectra and fluorescence channel images.
- `results/` contains selected baseline-correction, peak-comparison, fluorescence, and unknown-sample figures.

## Excluded Contents

Submitted reports, copied instruction material, and duplicated working files are excluded.

## Reproducibility Note

The included spectra and images are non-identifying lab measurement artifacts suitable for public review.
